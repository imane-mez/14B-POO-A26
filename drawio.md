# Éditeur de diagrammes

L’éditeur draw.io ci-dessous permet de créer des diagrammes avec l’interface complète de diagrams.net.

- Pour une utilisation plus confortable, utilisez le mode **Plein écran**.
- Utilisez **Enregistrer** pour conserver le diagramme dans ce navigateur. 
- **Important** : Enregistrez votre travail avant tout changement de page afin de ne pas perdre votre travail!
- Avant de quitter, utilisez **Télécharger (.drawio)** pour obtenir le fichier à remettre sur **Léa**. Attention: vous devez enregistrer le diagramme avant de le télécharger.
- La librairie personnalisée **Bloc-notes** est chargée automatiquement dans le panneau des formes.
- Le menu **Fichier** est désactivé dans cet éditeur.
