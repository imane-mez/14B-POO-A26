# Éditeur de diagrammes

L’éditeur draw.io ci-dessous permet de créer des diagrammes avec l’interface complète de diagrams.net.

- Utilisez **Enregistrer** ou `Ctrl+S` pour conserver le diagramme dans ce navigateur.
- Utilisez **Télécharger (.drawio)** pour obtenir un fichier réutilisable dans draw.io.
- Le diagramme enregistré est restauré automatiquement lors de la prochaine visite sur cette page.
- La librairie personnalisée **Bloc-notes** est chargée automatiquement dans le panneau des formes.
- Le menu **Fichier** est désactivé dans cet éditeur.
- L’importation de librairies reste disponible dans le panneau des formes.
